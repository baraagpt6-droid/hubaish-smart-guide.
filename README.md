# دليل مديرية حبيش

تطبيق ويب تقدمي (PWA) باللغة العربية للتعريف بمديرية حبيش في محافظة إب، اليمن.

## تشغيل محلي

يتطلب Node.js 22 أو أحدث.

```bash
npm install
npm run build
npm run preview
```

## النشر

يعمل سير العمل `.github/workflows/build-and-deploy.yml` عند الدفع إلى `main` أو يدوياً من GitHub Actions.

- ينشر محتويات `www/` إلى GitHub Pages.
- يبني تطبيق Android بصيغة APK ويرفعه كـ workflow artifact.
- عند إنشاء وسم يبدأ بـ `v`، يرفق APK بإصدار GitHub Release.

## حدود النسخة

المساعد الموجود داخل التطبيق محلي ويبحث في المحتوى المضمّن. لا يتصل بخدمة ذكاء اصطناعي سحابية. بيانات الإدارة المحلية تحفظ على الجهاز ولا تتزامن بين الأجهزة.
