# دليل مديرية حبيش

تطبيق ويب تقدمي عربي (PWA) مع حاوية Capacitor لتجهيز Android وiOS. ملفات التشغيل المنشورة موجودة في `www/`، ويديرها `www/app.js` و`www/catalog.js` و`www/features.js`.

## الوظائف

- واجهة عربية وإنجليزية وتركية وفرنسية، مع اتجاه نص مناسب وحفظ تفضيل اللغة محلياً.
- دليل أساسي يضم 19 معلماً، و22 عزلة، و7 محطات تاريخية، و4 شخصيات، و4 مراجع، واختباراً من 10 أسئلة.
- بحث وتصفية وتفاصيل ومفضلة ومساعد محلي ومواقيت صلاة تقديرية.
- GitHub JSON CMS لمشاركة الإضافات والتعديلات عبر ملف `www/data/live-content.json`.
- Service Worker وOffline Cache لفتح التطبيق والبيانات المحفوظة بعد انقطاع الإنترنت.
- حاوية Capacitor لبناء Android.

## GitHub JSON CMS

الملف العام هو `www/data/live-content.json`. يحتوي على المجموعات التالية:

- `landmarks`: تعديلات المعالم الأساسية والإضافات الجديدة.
- `historyEvents`: تعديلات المحطات التاريخية والإضافات الجديدة.
- `subDistricts`: أسماء مترجمة وملفات وصفية للعزل الـ22، مع بقاء سجل العزل الأساسي ثابتاً.
- `subDistrictUpdates`: القرى والمواضع والوصف المحلي المرتبط بكل عزلة.
- `historicalFigures`: تعديلات الشخصيات الأربع والإضافات الجديدة.
- `communityLinks`: روابط المجتمع، ومنها رابط المجموعة الرئيسي.

يحمل التطبيق الملف من `raw.githubusercontent.com` باستخدام طلب دون كاش قديم، ثم يحتفظ بنسخة JSON محلية في `localStorage` ليستخدمها عند تعذر الاتصال. ويضيف Service Worker ملف JSON المحلي إلى App Shell ليبقى هناك مصدر احتياطي عند تثبيت التطبيق أو تحديثه.

تُقرأ البيانات للجميع دون تسجيل دخول. أما النشر فيتم من لوحة GitHub CMS عبر GitHub Contents API.

### إعداد رمز المشرف

1. افتح [GitHub Fine-grained Personal Access Tokens](https://github.com/settings/personal-access-tokens/new).
2. اختر الوصول إلى المستودع `baraag6-droid/hubaish-smart-guide.` فقط.
3. امنح `Contents: Read and write` و`Metadata: Read`.
4. اختر مدة صلاحية تناسب سياسة حسابك، ثم أنشئ الرمز.
5. من التطبيق افتح «المزيد» ثم «لوحة إدارة الموسوعة المنشورة»، وأدخل الرمز للتحقق.

يُحفظ الرمز في متغير ذاكرة داخل صفحة المشرف فقط. لا يكتب في `localStorage`، ولا يضاف إلى JSON أو أي ملف في GitHub. يُمسح عند تسجيل الخروج أو إعادة تحميل الصفحة أو إغلاقها. لذلك سيحتاج المشرف إلى إدخاله من جديد في الجلسة التالية.

لا تستخدم Fine-grained Token بصلاحية جميع المستودعات، ولا تستخدم Token بصلاحية حذف المستودع أو الإدارة العامة. لا تشارك الرمز ولا تضعه في نسخة احتياطية.

### قواعد تحرير المحتوى

- يمكن تعديل المعالم والمحطات والشخصيات الأساسية، وحفظ التغييرات كطبقات تتجاوز النص الأساسي دون إتلافه.
- لا يُحذف أي عنصر أساسي من العناصر التي تحقق الأعداد المطلوبة. عند اختيار «إعادة للأصل» يُحذف التعديل السحابي فقط.
- يمكن إضافة القرى والمواضع وروابط المجتمع، وتعديلها أو حذف الإضافات المنشورة.
- تبقى العزل الـ22 موجودة. يمكن تعديل ترجمة اسم العزلة ووصفها، ولا يمكن حذفها من القائمة الأساسية.
- يحاول التطبيق ترجمة الحقول الناقصة إلى الإنجليزية والتركية والفرنسية قبل النشر. تعتمد الترجمة الآلية على MyMemory المجانية؛ عند تعذر الخدمة أو بلوغ حصتها، أدخل الترجمات يدوياً ثم انشر.
- ينشئ كل نشر commit جديداً في المستودع. إذا حدث تعارض متزامن، يعيد التطبيق قراءة الملف ويحاول مرة واحدة قبل إظهار الخطأ.

### حدود الخدمة

هذا النظام مجاني ضمن الاستخدام المتاح في GitHub، لكنه ليس قاعدة بيانات مضمونة بتوافر 24/7 مدى الحياة. يعتمد التحديث العام على GitHub وRaw CDN والإنترنت. قد تتأثر الخدمة بانقطاع GitHub، أو حدود API، أو حذف المستودع، أو تعطل Pages، أو انتهاء/إلغاء رمز المشرف. النسخ المحلية تسمح بالقراءة دون اتصال، لكنها لا تستقبل تحديثات جديدة حتى عودة الاتصال.

لا يستطيع الزائر المجهول الكتابة مباشرة إلى المستودع. مساهمات الزوار تحفظ محلياً على جهازهم للمراجعة؛ النشر العام يتم من لوحة المشرف فقط. تحرير JSON من أكثر من مشرف في اللحظة نفسها قد ينتج تعارضاً؛ راجع الرسالة وأعد المحاولة بعد قراءة النسخة الأحدث.

## الدقة وحدود البيانات

- عدد السكان 105,998 يعود إلى تعداد 2004.
- مساحة المديرية غير محسومة بين المراجع التي تمت مراجعتها؛ تستخدم الواجهة 228 كم² في جدول OCHA/Local Governance وتذكر وجود مرجع محلي يورد 330 كم².
- الارتفاع والإحداثيات والمسافات تقريبية. رادار المسافة ليس نظام ملاحة GPS.
- مواقيت الصلاة تقديرية ويجب مطابقتها مع تقويم المسجد المحلي.
- لا تعرض الواجهة أسماء قرى غير موثقة على أنها حقيقة.
- الروايات التاريخية المحلية تبقى موسومة بالحاجة إلى توثيق عندما لا يتوفر مصدر كافٍ.

## النسخ الاحتياطي

زرّا «تصدير JSON» و«استيراد JSON» يحتفظان بنسخة بيانات التطبيق المحلية. هذه النسخة لا تحتوي على رمز GitHub. أما نسخة CMS المشتركة فيمكن تنزيلها مباشرة من:

`www/data/live-content.json`

## التطوير والتحقق

يتطلب Node.js 22 أو أحدث.

```bash
npm install
npm run build
npm run preview
```

يتحقق `npm run build` من الملفات، واللغات، وكتالوج المحتوى، وGitHub CMS، ومفتاح المشرف داخل الذاكرة فقط، والـ Manifest، وService Worker، وCapacitor، وملفات Android، وأيقونات PNG. افتح المعاينة عبر `http://127.0.0.1:4173`.

## Android والنشر

يستخدم المشروع Capacitor 8.6.2. ينشر سير العمل `.github/workflows/build-and-deploy.yml` الموقع إلى GitHub Pages ويبني APK. وينشر Release دائماً فقط عند ضبط أسرار توقيع Android الأربعة:

- `KEYSTORE_BASE64`
- `KEYSTORE_PASSWORD`
- `KEY_ALIAS`
- `KEY_PASSWORD`

احتفظ بنسخة احتياطية من keystore واستخدم المفتاح نفسه لكل الإصدارات اللاحقة. لا ترفع keystore أو كلمات مروره إلى المستودع. عند غياب أسرار التوقيع، ينتج سير العمل APK تجريبياً في Actions Artifacts لمدة 30 يوماً ولا ينشئ Release دائماً.

رابط التنزيل الدائم بعد نشر Release موقع هو:
`https://github.com/baraagpt6-droid/hubaish-smart-guide./releases/latest/download/hubaish-smart-guide.apk`

قد تحتاج إلى إزالة APK تجريبي قبل تثبيت أول APK موقع، إذا كان مفتاح التوقيع مختلفاً.
